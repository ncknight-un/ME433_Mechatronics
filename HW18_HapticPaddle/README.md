
# Haptic Paddle 

I worked with Greg Aiso for this final project. We slit up the work between different components.
We chose to use just the Pico for this project, as we thought it would make it easier for the two of us to 
collaborate together. 

We chose to develop a pygame for the haptic paddle, where the user is trying to drive a car down a road with obstacles. If you squeeze the force load cell, the car will speed up. You can make it turn back and forth by moving the paddle back and forth, which is read by the Encoder. The Current Sensor and H-Bridge provide haptic feedback for the paddle, where if an obstacle is hit, it will act as a "pothole" signal, and if you push off the road, a large torque is applied by the motor to push you back onto the road.
